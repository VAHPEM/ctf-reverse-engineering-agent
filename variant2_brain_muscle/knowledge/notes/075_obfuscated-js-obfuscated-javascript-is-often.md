Obfuscated JavaScript is often the output of the open-source `javascript-obfuscator`; recognize its style and run the matching open-source deobfuscator (obfuscator.io Deobfuscator), then beautify. Expect a decoy base64 blob planted to waste time. Recover the expected inputs via browser DevTools and replay them to trigger the flag.
